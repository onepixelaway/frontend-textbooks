# Visual System

## Page rhythm

Mix page types to suit the source: measured two-column analytical pages, spacious single-column emphasis, compact three-column references, diagrams, image plates, tables, exercises, and intentional closers. Avoid an uninterrupted article-like flow.

Whitespace must look owned. Repaginate or redesign hollow tail pages. For 4–6 short tool items, prefer horizontal rows with strong item headers over skinny equal columns.

## Diagram grammar

- Comparison: paired rows, equal columns, or a matrix.
- Sequence: numbered process or timeline with one direction.
- Cycle: a loop only when recurrence is real.
- Hierarchy: tree, layers, or stack.
- Anatomy: direct callouts on an object or scenario.
- System: minimum useful nodes and links; split spaghetti networks.
- Reusable tool: canvas or framework grid with portable labels.

Give every exhibit an internal premise/title, clear reading order, manuscript vocabulary, a visible takeaway, and a caption. Remove decorative lines and shapes that encode nothing. Use inline SVG/HTML for crisp exact labels; use a generated diagram image after writing a visual specification when spatial complexity would make code brittle.

## Signature tools

When supported by analytical material, add a reusable framework/canvas, chapter-ending model cards, and an annotated failure/anatomy page. Keep them additive and source-faithful. They must feel like designed artifacts, not generic boxed callouts.

## Images

Use manuscript-grounded prompts, deliberate crops, meaningful alt text, and adequate print resolution. Keep exact small text in HTML/SVG. Never reuse cover art inside the book or repeat one divider image across parts.

## Cover gate

The final cover must match the selected route's composition, crop, hierarchy, metadata placement, and negative space. Compare the selected option and final render before approval.
